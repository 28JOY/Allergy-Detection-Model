# Allergy Detection Model 🤧🔬

This project was developed as a **group project** for the **Machine Learning coursework in Semester 5** of B.Tech in Computer Science and Business Systems.

## 📌 Project Overview

The **Allergy Detection Model** is a rule-based + machine learning system designed to predict the likelihood of a food allergy based on user-reported symptoms and food product data. It allows users to input allergic reactions and evaluates which foods might be risky, offering visual insights and predictions.

## 🛠️ Features

- 🧠 **Symptom-to-Allergy Mapping**  
  Rule-based logic to flag potential allergens based on user-input symptoms.

- 📊 **Interactive Visualizations**  
  Bar charts and heatmaps to visualize allergy distributions, model accuracy, and performance metrics.

- 🤖 **Model Comparison**  
  Compares three ML models:
  - Logistic Regression
  - Naive Bayes
  - Support Vector Machine (SVM)

- 📈 **Performance Metrics**
  Includes accuracy, precision, recall, and F1-score visualized for each model.

## ⚙️ Technologies Used

- Python 🐍  
- Libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

## 📂 Dataset

The dataset `datasetfoodallergy123.csv` includes:
- Food products and associated allergens
- User symptoms
- Nutrition information

📁 **Note:** The dataset used in this project is a custom dummy dataset created by us to simulate real-world food allergy cases.

_(The dataset is kept local and excluded from the repository for simplicity.)_


## 💡 Usage

1. Run the script.
2. Input the food product and symptoms when prompted.
3. View prediction output and performance of different classifiers.
